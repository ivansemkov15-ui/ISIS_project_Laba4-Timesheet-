# Timesheet – проектирование системы учёта рабочего времени

**Лабораторная работа №4** (проектирование требований)

## Диаграмма Use Case

Основные роли:
- Сотрудник
- Руководитель
- Администратор

Варианты использования: добавление часов, редактирование записей, просмотр отчётов, утверждение.

## User Story Map (роль: Сотрудник)

Активности:
1. Ввод времени
2. Управление записями
3. Просмотр и отчёты

### Истории MVP (выше линии приоритета)

- Как сотрудник, я хочу добавить часы работы за день с выбором проекта.
- Как сотрудник, я хочу редактировать уже созданную запись.
- Как сотрудник, я хочу видеть свои часы за последние 7 дней.
- Как сотрудник, я хочу получить сумму часов по проектам за текущий месяц.

Остальные истории (удаление записей, CSV‑отчёт, утверждение руководителем) — в следующих версиях.
