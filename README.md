# Timesheet – учёт рабочего времени

Небольшое веб-приложение (или скрипт) для ведения табеля рабочего времени.  
Позволяет сотрудникам добавлять часы по проектам, редактировать записи и получать простые отчёты.

## Как это работает

- Добавление записи: указывается дата, проект, количество часов (с шагом 0.5).
- Просмотр своих часов за неделю в виде списка.
- Суммарные часы по проектам за текущий месяц.
- Редактирование и удаление существующих записей (в плане).

## Текущий бэклог (MVP)

1. Добавление записи о часах с выбором проекта.
2. Редактирование созданной записи.
3. Просмотр часов за последние 7 дней.
4. Подсчёт суммы часов по каждому проекту за месяц.

Остальные функции (выгрузка в CSV, утверждение руководителем) – на потом.

## Запуск

```bash
python timesheet.py
